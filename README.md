# Whitepace Project

Recriação de uma landing page baseada em um layout do Figma, desenvolvida com HTML e CSS.

## 🚧 Status

Em desenvolvimento.

O projeto ainda está sendo construído e receberá novos ajustes de layout, responsividade, interações e funcionalidades.

## 🎯 Objetivo

Praticar e aprimorar conhecimentos em desenvolvimento web, principalmente:

- Estruturação semântica com HTML
- Estilização e responsividade com CSS
- Organização e reutilização de estilos
- Desenvolvimento de interfaces a partir de layouts do Figma
- Versionamento de código com Git e GitHub

## 🛠️ Tecnologias

- HTML5
- CSS3
- Git
- GitHub
